### Rankings

- Options, account, sort and limits are validated. Unsupported historical-margin ranking is rejected rather than sorting unknown margins as zero. ES failures propagate as unavailable; incomplete/truncated/approximate aggregates, missing indexed line-item fields and missing/mixed currencies fail closed.
- Comparisons use adjacent equal-duration half-open UTC windows, including elapsed YTD. Exact reverse-nested order counts replace approximate cardinality. The bounded universe is products observed in either complete indexed window, retaining disappeared products, not a claim about the entire catalog or live provider ledger.
- Zero-base growth, historical margin and unsupported monetary summaries remain null. A persisted single currency is required across both windows. Metadata lookups are account-scoped; missing metadata remains explicitly unavailable. This does not certify that upstream indexed amounts or status conventions are a complete accounting ledger.

### Invoice canvas and rich-text links

- The canvas now has a fixed 12-column paper coordinate system, horizontally scrollable on narrow displays. Initialization/viewport layout callbacks do not save anything; only explicit drag/resize stop events commit validated, bounded geometry with the same item identities. Drop kinds, item types/content/styles, child references and item counts are checked. Sidebar insertion remains the keyboard alternative; individual/row-child selection supports Enter/Space.
- Media URLs are restricted; source-keyed React image failure state replaces persistent imperative DOM mutation. The preview explicitly disclaims final PDF equivalence, sample values, QR and auto-fit accuracy. No customer PDF was generated to verify it.
- Toolbar links require explicit HTTP(S), mailto or tel URLs without credentials, controls, whitespace or unresolved merge tags. Link creation restores the captured range and supplies target/rel policy. Configured merge-tag insertion rejects values outside its supplied list. This is a toolbar policy, not a claim that every imported/pasted link or downstream renderer has been audited.
- Link dialogs are named, trap Tab, handle Escape, prevent input Enter from submitting an enclosing form and restore trigger focus. Text/list controls expose pressed state, editor updates refresh formatting state, and Lexical's selected-block formatting command replaces anchor-only alignment.

### Canonical invoice generation and attachments

- Artifact identity includes selected account, resolved internal order, template/version/design hash and observed order version. Only the mutable numbering counter is excluded from design identity. Polling requires the full immutable identity. The existing public artifact download remains signature-capability authenticated; it was not misclassified as an unauthenticated arbitrary-ID lookup.
- Queue workers must win a conditional `pending → generating` claim. Source provenance is rechecked before rendering; terminal writes are scope/status conditional. Attachment and relay inline fallbacks were removed. A slow queue returns pending; it never starts another render to hide an outage.
- An admitted failed/ambiguous generation is retained as `uncertain`; it is not reset/retried automatically. Existing invalid/forced-refresh artifacts require explicit reconciliation. Routes return a conflict for uncertain/reconciliation-required outcomes instead of claiming ordinary pending/success. This intentionally removes blind regeneration behavior; external callers/operators must adapt.
- Number reservation uses template account/version compare-and-set with a strictly advanced timestamp. It is never rolled back/retried merely because rendering or acknowledgement failed. The renderer writes UUID filenames under a checked account directory, and importing it no longer creates directories.
- Readiness requires the canonical renderer, full identity, generated timestamp, PDF MIME, account-root realpath confinement, non-symlink regular file, bounded matching size and `%PDF-` header. These checks establish an eligible stored artifact, not complete PDF validity, legal numbering correctness, durable storage integrity or visual equivalence. Failed renders can leave an orphan file or reserved sequence gap requiring operator reconciliation; no automatic destructive cleanup was added.

### Synthetic scripts and flow edges

- Setup/seed/reset modules are import-safe read-only planning wrappers. CLI defaults to dry-run and requires explicit development/test environment, database destination and UUID account. Apply requires the reviewed whole-plan digest; the transaction re-plans under serializable isolation and an account lock and retains a receipt.
- Setup refuses existing identities and requires a new `@example.invalid` user, disconnected `.invalid` account marker and an explicitly supplied nonlogged 20–200-character secret, hashed with Argon2id. It never adopts a user's existing membership or returns a password.
- Seed is create-only on empty proven synthetic accounts, bounded to 200 products/customers/orders each, with deterministic fixture IDs and an explicit nonfuture timestamp. Customer/order monetary totals derive from coherent seeded line items. It does not index, emit lifecycle events or create subscriptions.
- Reset requires matching synthetic ownership, unchanged membership, row markers and reviewed fingerprints/versions. It refuses oversized/mixed data, product/customer relation dependents and known operational dependencies; deletes are account/version/marker conditional and transactional. There is no automatic reseed, search deletion or claim of search cleanup. Manually introduced logical dependencies/search projections still require separate review; do not run these scripts against real data to discover their behavior.
- Edge insertion controls remain visible for touch/focus and use their DOM rectangle rather than keyboard `(0,0)` coordinates. The parent checks current `manage_marketing`, endpoints, flow identity and the same edge/source/target/handle snapshot again before step/action insertion. This is not a replacement for server publication authority or a full review of all other graph mutations.
